# OBS によるシーン切替

controller（ブラウザ）は、ミュートと同じ OBS WebSocket の接続で、OBS の番組シーンを controller の「シーン指示」に合わせる。シーン指示はぶらり旅の再生と CM モードで変わる。接続の仕組み、エラーの扱い、接続情報のエンドポイントは docs/obs-mute.md に書いたものを使う。

## 1. 前提

### 1.1 シーン

OBS には次の3つのシーンを用意する。名前は環境変数で変えられる（4.3）。

| シーン指示 | 用途                   | 名前の初期値   |
| ---------- | ---------------------- | -------------- |
| `normal`   | 公演中と転換中の通常時 | `Normal_Scene` |
| `cm`       | 転換中の CM モード     | `CM_Scene`     |
| `burari`   | ぶらり旅の動画を流す間 | `Burari_Scene` |

### 1.2 番組シーンの持ち主

番組シーンは controller が切り替える。OBS 上で手で別のシーンにしても、controller は次にシーン指示が変わるか、OBS に接続し直すまで戻さない。

## 2. 使うリクエスト

| リクエスト               | 引数        | 応答 | 用途                   |
| ------------------------ | ----------- | ---- | ---------------------- |
| `SetCurrentProgramScene` | `sceneName` | なし | 番組シーンを切り替える |

スタジオモードでも、このリクエストはプレビューを経ずに番組シーンを切り替える。指定した名前のシーンがなければ 600 `ResourceNotFound` のエラーになる。

## 3. シーン切替の仕様

### 3.1 シーン指示の決め方

`Controller` の状態から、上の行ほど優先して決める。

| 状態             | シーン指示 |
| ---------------- | ---------- |
| ぶらり旅の再生中 | `burari`   |
| CM モード        | `cm`       |
| それ以外         | `normal`   |

シーン指示はメモリだけに持つ。controller を開いた直後は CM モードが解除された状態から始まるので、開くたびに状態からシーン指示を決め直す。

### 3.2 切り替えるきっかけ

| きっかけ                           | 動作                                               |
| ---------------------------------- | -------------------------------------------------- |
| シーン指示が変わったとき（接続中） | `SetCurrentProgramScene` を送る                    |
| シーン指示が変わったとき（未接続） | シーン指示だけを持っておく                         |
| 接続完了（再接続を含む）           | シーン指示があれば `SetCurrentProgramScene` を送る |

ミュート（docs/obs-mute.md 3.4）と違い、未接続のときもエラーにしない。シーン指示は今の状態から決まり、接続後に送っても古い指示にはならないためである。OBS を終了して起動し直すと、再接続したときに今の状態のシーンへ戻る。

### 3.3 失敗したとき

シーンが見つからないときやタイムアウトしたときは、コンソールにエラーを出す。画面には出さない。

## 4. 実装

### 4.1 OBS クライアント（`src/api/obs/obsClient.ts`）

- `setScene(scene): Promise<void>`: シーン指示を変え、接続中なら番組シーンを切り替える。未接続のときは何も送らずに終わる。
- 接続が完了したら、ミュートのかけ直しと並べてシーン指示のシーンへ切り替える。

### 4.2 呼び出し元（`src/pages/Controller.tsx`）

CM モードとぶらり旅の再生状態が変わるたびに、3.1 の表でシーン指示を決めて `obsClient.setScene` を呼ぶ。

### 4.3 シーン名

シーン名は `GET /obs/config` の `scenes` で受け取る。環境変数と初期値は docs/obs-mute.md 4.3 の表にある。

### 4.4 モックモード

`VITE_API_MODE=mock` のときは OBS に接続しないので、シーンも切り替えない。

## 5. 動作確認

起動の手順は docs/obs-mute.md 6.1 と同じである。OBS に 1.1 の3つのシーンを作っておく。

1. CM モードにすると CM のシーンに、解除すると通常時のシーンになる。
2. ぶらり旅を再生すると、ぶらり旅のシーンになる。再生が終わるか止めると、CM モードなら CM のシーン、そうでなければ通常時のシーンに戻る。
3. CM モードのまま OBS を終了して起動し直すと、再接続したあとに CM のシーンになる。
4. シーン名を存在しない名前にすると、切り替えのたびにコンソールにエラーが出る。
